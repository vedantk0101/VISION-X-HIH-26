# VISION-X — Vision-Based Autonomous Robot

**Hack In Hills '26 | Problem Statement 01**  
**Team:** Tech Titans

## Overview

VISION-X is a low-cost autonomous mobile robot designed to perceive its surroundings, detect obstacles, make navigation decisions, and move toward a designated objective without continuous human control.

The project combines embedded robotics with computer vision to explore intelligent autonomous navigation.

## Objectives

- Build a functional wheeled robot.
- Detect obstacles and avoid collisions.
- Integrate a camera-based perception system.
- Explore autonomous target navigation.
- Demonstrate the technical feasibility of a low-cost autonomous rover.

## Proposed Technology Stack

**Hardware**
- Arduino Mega 2560
- DC geared motors and robot chassis
- Motor driver
- Ultrasonic distance sensor
- Smartphone camera
- Windows laptop

**Software**
- Arduino C/C++
- Python
- OpenCV
- Computer-vision model to be selected and integrated
- Git and GitHub

## System Architecture

Camera → Visual Perception → Decision Logic → Arduino Controller → Motor Driver → Robot Movement

Distance sensors provide additional obstacle information to the controller.

## Development Plan

1. Assemble and test the robot.
2. Implement motor control.
3. Implement autonomous obstacle avoidance.
4. Integrate camera input and computer vision.
5. Develop and test a simple autonomous mission.
6. Document results and prepare a prototype demonstration.
