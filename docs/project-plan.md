
# VISION-X Prototype Development Plan

## Stage 1: Hardware Setup
- Assemble the robot chassis.
- Connect the motors and motor driver.
- Connect the ultrasonic sensor.
- Configure the power supply.

## Stage 2: Autonomous Movement
- Implement motor control.
- Measure obstacle distance.
- Stop and turn when an obstacle is detected.

## Stage 3: Computer Vision
- Connect the smartphone camera to the laptop.
- Process camera frames using Python and OpenCV.
- Integrate an object-detection model.

## Stage 4: Testing
- Test obstacle avoidance.
- Test camera-based object detection.
- Record the working prototype demonstration.

## Status
Planning stage. Features will be marked complete
after implementation and testing.
